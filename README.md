# Loop City: Bus Jam V2

原创纯前端休闲益智游戏工程，提供 100 关、关卡代码、关卡选择、金币、提示、撤销、洗牌、四套场景主题和本地进度保存。

## 启动
直接打开 `index.html`，或将整个目录上传到 GitHub Pages。

## 关卡区间
- 1-25：城市
- 26-50：海滨
- 51-75：夜景
- 76-100：冬季

## 美术
`assets/original-asset-sheet.png` 是本项目生成的原创商业手游风格视觉资产基准。`assets/visual-direction.png` 为用户提供的概念方向图，仅作为本地设计参考，不在运行时加载。当前运行版使用 HTML/CSS 绘制元素，保证加载速度和可部署性。

# Bus Loop V3
Enhanced private-use HTML5 recreation with bus sprites, passenger sprites, irregular free placement, start-up shake, drive-out easing, passenger boarding animation, blockers, parking, undo, hint and local progress.

Open index.html directly. No build step.

Note: supplied walkthrough videos are visual references. This build does not claim frame-perfect coordinates for every recorded level; exact level coordinate extraction requires structured original level data or manual transcription per level.

# Loop City Deluxe

重资产、图片驱动的纯前端网页版益智游戏。运行时不使用 Canvas、SVG 或程序绘制的巴士/乘客/场景，主要视觉均为 PNG 图片资产。

## 运行
解压后直接打开 `index.html`，或把整个文件夹部署到 GitHub Pages。

## 内容
- 100 关与 `LOOP-XXX-XX` 关卡代码
- 城市、海滨、夜景、冬季四套高分辨率场景
- 六色图片巴士和乘客资源
- 巴士环路、同色载客、容量、等待车位、撤销、提示、洗牌
- 关卡选择、金币、三星通关和反馈动画

## 素材
游戏场景和角色资源为本项目原创生成资产。`concept-reference.png` 仅做内部视觉方向参考，运行时不加载。

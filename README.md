# Loop City: Bus Puzzle

原创高品质商业手游风格的纯前端网页游戏，共 100 关。

## 运行

直接打开 `index.html`，或将整个目录上传到 GitHub Pages / Netlify / Cloudflare Pages。

## 功能

- 原创卡通城市和环岛美术
- 彩色巴士、乘客、上车与离场动画
- 前 20 关独立难度曲线，后续扩展到 100 关
- 环路容量、前三辆可选、撤销、提示、洗牌
- 关卡选择和浏览器本地存档
- `LOOP-XXX-XX` 关卡代码与校验
- 手机、平板和桌面响应式布局

## 注意

视频仅用于理解“彩色巴士匹配乘客、环路容量和出车顺序”的玩法类别。项目不包含原游戏图片、音频、Logo、源代码或逐关布局。

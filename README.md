# Loop City: Bus Jam

原创纯前端网页版益智游戏原型。包含 100 关、确定性关卡生成、关卡代码、关卡选择、撤销、提示、洗牌、本地进度与移动端布局。

## 运行
直接打开 `index.html`，或用任意静态服务器部署到 GitHub Pages。

## 关卡代码
每关都有唯一的 `LOOP-XXX-XX` 代码。通关弹窗可复制，首页可输入并继续对应关卡。

## 文件
- `index.html` 页面结构
- `styles.css` 原创视觉和响应式布局
- `game.js` 100 关、代码验证、玩法与本地进度
